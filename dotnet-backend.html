HOW IT WORKS

A Structured Journey from Learning to Implementation.

كل Session جزء من رحلة بناء المشروع. بتتعلم مفهوم، تشوف تطبيقه Live، وبعدها تنفذه بنفسك، وتستقبل Feedback قبل الانتقال للخطوة التالية.

1

Learn

شرح المفهوم التقني وفهم الهدف منه ودوره داخل المشروع.

2

Build Live

المدرب بيطبق المفهوم ويبني الجزء الخاص بيه داخل المشروع خطوة بخطوة.

3

Implement Your Task

بتنفذ الجزء المطلوب بنفسك على Branch خاص بالـ Feature.

4

Submit & Review

5

Improve & Move Forward

بتستقبل Written Feedback، وتناقش الملاحظات، وبعدها تنتقل للـ Feature التالية.

YOUR PRACTICAL PROJECT

Build an Online Course Registration System.

خلال البرنامج هتبني Backend لمنصة Online Course Registration System لإدارة الكورسات وتسجيل الطلبة. المشروع بيحاكي احتياج Business حقيقي، وبيخليك تطبق مفاهيم Backend على Application واحدة متكاملة.

👤 Student 🧑‍🏫 Instructor 🛡️ Admin

What the System Supports

  • Course Management.
  • Categories & Instructor Management.
  • Course Enrollment.
  • Account Creation and Login.
  • Roles and Permissions.
  • Search and Filtering.
  • Pagination.
  • Logging.
  • Documentation.
  • Testing.

Core Business Rules

  • Prevent duplicate enrollment in the same course.
  • Respect the maximum number of available seats.
  • Apply different permissions according to user roles.
  • Handle invalid operations and business errors appropriately.
Each trainee designs an ERD based on the Business Description. After reviewing the designs, one reference database design is approved for all trainees to continue building upon, following one organized Architecture throughout the program.
