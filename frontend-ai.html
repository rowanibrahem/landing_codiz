Real-world bugs. Unclear AI outputs. Security risks. Your decisions matter.

مش كل حاجة الـAI بيبنيها بتكون صح، ومش كل Code بيشتغل معناه إنه جاهز للاستخدام.
أثناء تطوير أي Project، هتقابل Bugs، وRequirements مش واضحة، ومشاكل في الـIntegration والـSecurity. هتحتاج تفكر، وتحلل، وتختبر، وتتعامل مع التحديات دي باستخدام مهاراتك وأدوات الذكاء الاصطناعي.

1. Unclear Project Requirements

مش كل فكرة بتكون واضحة من البداية. هتتعلم إزاي تفهم المطلوب، تحدد الـFeatures، وتحول الفكرة إلى خطوات قابلة للتنفيذ.

🐛

2. AI-Generated Code Problems

مش كل Code بيكتبه الـAI بيكون صحيح. هتتعلم تراجع الكود، تكتشف الـBugs، وتعمل Debugging بدل ما تعتمد على النتيجة بشكل أعمى.

🛡️

3. Security & Missing Validations

تطبيقك ممكن يشتغل بشكل ممتاز، لكن يكون فيه ثغرات أمنية أو مشاكل في التعامل مع بيانات المستخدمين. هتتعلم إزاي تكتشف المخاطر دي وتتعامل معاها.

🔁

4. Unexpected Changes & Integration Issues

العميل ممكن يطلب تعديلات في أي وقت، وإضافة Feature جديدة ممكن تأثر على أجزاء موجودة بالفعل. هتتعلم إزاي تتعامل مع التغييرات وتختبر الـApplication بعد كل تعديل.

WHAT WILL YOU LEARN?

Your Frontend + AI Learning Journey.

من أساسيات تطوير الويب إلى بناء تطبيقات حقيقية باستخدام أدوات الذكاء الاصطناعي، هتتعلم وتطبق خطوة بخطوة خلال 10 Live Sessions.

01
SESSION 01

Introduction to Web Development & AI

التعرف على عالم الـWeb Development، وفهم دور الـFrontend، وإزاي الذكاء الاصطناعي بيغير طريقة بناء وتطوير التطبيقات.

02
SESSION 02

HTML & CSS Fundamentals

بناء هيكل صفحات الويب باستخدام HTML، وتنسيق الواجهات باستخدام CSS، مع تطبيقات على Responsive Design.

03
SESSION 03

JavaScript & Interactive Web

تعلم أساسيات JavaScript، والتعامل مع البيانات والأحداث، وإضافة التفاعل والـDynamic Behavior لصفحات الويب.

04
SESSION 04

React & Component-Based Development

فهم Components وProps وState، وبناء واجهات تفاعلية.

05
SESSION 05

Git, GitHub & Working with APIs

التعرف على أساسيات Git وGitHub، وتنظيم ملفات المشروع، والتعامل مع الـAPIs وفهم أساسيات ربط الـFrontend بالـBackend.

06
SESSION 06

AI-Assisted Development with GitHub Copilot

استخدام GitHub Copilot وأدوات الذكاء الاصطناعي في كتابة الكود، وفهمه، وتحسينه، وحل المشكلات أثناء التطوير.

07
SESSION 07

Vibe Coding with Lovable

تحويل الأفكار إلى واجهات وتطبيقات باستخدام Prompt Engineering، وتطوير الـUI من خلال التوجيه والتعديل التدريجي.

08
SESSION 08

AI Coding Agents with OpenCode

التعرف على Coding Agents، وفهم Project Structure، وتوجيه الـAgent لتنفيذ المهام ومراجعة التغييرات.

09
SESSION 09

Testing, Debugging & AI Security

اختبار التطبيقات، واكتشاف الـBugs، ومراجعة الكود الناتج عن AI، والتعرف على أساسيات الأمان وحماية البيانات.

10
SESSION 10

Final Project & Practical Showcase

تطبيق المهارات المكتسبة في مشروع عملي، ومراجعة النتائج، وتحسين التطبيق، وتجهيز المشروع للعرض والتقديم.
